## Magazine reader

`js/magazine-viewer.js` and `css/magazine-reader.css` provide a native dialog with desktop spreads, single pages on phones, a lazy thumbnail overview, page-number entry, a progress slider, keyboard and swipe navigation, zoom, and fullscreen. There is no PDF button or PDF fallback link. Covers and final back covers display individually; internal pages pair even/odd to preserve printed spreads. A decoded page replaces the current page only when ready, with retries for failed requests. Fullscreen targets the reader shell, including its controls, with compact toolbars and more room for the pages. Zoom keeps the clicked point under the pointer while high-resolution images load; toolbar and keyboard zoom use the center of the reading area. Closing restores focus and scrolling; reopening remembers the reading position during the visit.

`content/magazines.json` records the nine source PDFs. Run `npm run images:magazines` (Poppler's `pdfinfo`/`pdftoppm` and Sharp required) to generate all 672 pages and `js/magazine-library.js`. An optional issue id renders just that issue; run the full command afterward to refresh the shared library. Source PDFs are unchanged. Generated assets in `images/magazines/` use 240px WebP thumbnails, 960px reading pages, and 1920px zoom pages, with a source/recipe hash for cache invalidation. The build skips complete, unchanged issues. Commit generated assets along with their manifests and library; the static host needs no PDF renderer or build dependency.

Reading fetches only the current pages and a small neighborhood (two ahead, two behind), with a 12-image memory cache. Prefetch pauses when the reader closes, changes position, or the connection requests reduced data. Zoom images and thumbnail previews load only when requested. No source PDF or external PDF.js library is downloaded during normal reading. `tests/magazines.cjs` checks all publication assets, responsive page fit, navigation, zoom, retries, request races, focus restoration, fullscreen sizing, anchored zoom, and the absence of PDF links. Set `BROWSER_ENGINE=webkit` and `BROWSER_PATH` to a compatible WebKit executable to run these checks against WebKit.
